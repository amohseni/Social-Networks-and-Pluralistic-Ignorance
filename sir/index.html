How the model works

Agents and states. Each of the n agents is susceptible, infectious or removed. Every agent starts susceptible. Infection enters through the initially infectious agents (none by default), through spontaneous infection, or by clicking a node.

One tick. The agents that are infectious at the start of the tick act in random order. Each first advances its infectious clock. If the clock now exceeds periods infectious and perpetually infectious is off, the agent is removed and does nothing else this tick. Otherwise it infects each susceptible neighbor independently with the transmission probability. An agent therefore transmits for exactly periods infectious ticks and is removed on the tick after. Agents infected during a tick do not transmit until the next one. Then, with probability spontaneous infection, one uniformly random susceptible agent becomes infectious. The run stops when no susceptible agent remains, or when nothing can change any more (no infectious agents and spontaneous infection at 0).

Networks.

  • Random. Erdős–Rényi: each pair of agents is linked with probability network probability.
  • Small world. Watts–Strogatz: a ring where each agent is linked to its neighborhood size nearest agents on each side, then each link is rewired to a random agent with probability network probability. Neighborhood size must be at most (n − 1)/2.
  • Complete. Every pair of agents is linked.
  • Connected caveman. Agents are split into cliques of neighborhood size (the last clique takes the remainder), and one member of each clique is linked to one member of the next, in a ring.

Network statistics follow the NetLogo nw extension: the clustering coefficient is the mean local clustering over agents (an agent with fewer than two neighbors counts 0), and the mean path length is over all pairs when the network is connected; when it is not, it is reported for the largest component.

Provenance. A faithful port of the NetLogo model SIR-1.nlogo. Additions: initially infectious agents, click-to-infect, an explicit seed, a speed control, network statistics, and the data table. Defaults match the original interface.
