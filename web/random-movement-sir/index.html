How it works

A port of the NetLogo model RandomMovementSIR.nlogo (NetLogo 6.4.0), rule for rule. The world is 33 × 33 patches with wrapping on both axes. Each agent is susceptible, infectious, or removed.

  1. Setup. NumberOfPeople agents are placed on random patch centres; InitiallyInfectious of them start infectious.
  2. Stop rule. Go halts when no agent is infectious, or, with PerpetuallyInfectious on, when every agent is.
  3. Infectious agents, in random order: the infectious clock advances by one. If it exceeds PeriodsInfectious (and PerpetuallyInfectious is off) the agent is removed. Otherwise it picks one agent uniformly at random among those within Radius (torus distance) and, if that agent is susceptible, infects it with probability ProbTransmission.
  4. Removed agents: the removed clock advances by one. If it exceeds PeriodsRemoved (and PerpetuallyRemoved is off) the agent becomes susceptible again.
  5. Movement. Every agent turns right by a uniform integer number of degrees and steps forward one unit.

Things to notice

  • With both switches off and PeriodsRemoved = 1 the model is SIRS with one tick of immunity, so it need not die out. PerpetuallyRemoved on gives classic SIR.
  • Agents newly infected in a tick do not transmit until the next tick, but agents removed in a tick start their removed clock the same tick. An infection therefore lasts PeriodsInfectious + 1 ticks and immunity lasts PeriodsRemoved ticks.
  • The caller is inside its own radius, so each contact draw lands on the infectious agent itself with probability 1 / (agents in radius). With few agents nearby this wastes a sizeable share of contacts.
  • Contact is one draw per infectious agent per tick regardless of crowding, so transmission is frequency-dependent, not density-dependent. Radius 20 on a 33-wide torus reaches almost everyone, which makes the model well mixed; small radii make it spatial.
  • The NetLogo file saves NumberOfPeople = 1024 on a slider capped at 1000. The slider here runs to 2000.
Reproducibility

Enter a seed before Setup to reproduce a run in this app. The random stream differs from NetLogo's, so seeds do not match across the two.
